## 🌐 To Make It Accessible via QR Code

You need to host it online. Here are the EASIEST options:

---

### Option 1: Netlify (Recommended - 2 minutes) ⭐

1. Go to: https://app.netlify.com/drop
2. **Drag and drop** the entire `ieee day` folder
3. Get instant URL like: `https://random-name-123.netlify.app`
4. **Rename it** (optional): Site settings → Change site name → `ieeeday2026`
5. **Generate QR code** for the URL: https://www.qr-code-generator.com/

**Pros:**
- ✅ Free forever
- ✅ Takes 2 minutes
- ✅ HTTPS (secure)
- ✅ Works offline after first load
- ✅ Can update by dragging new files

---

### Option 2: GitHub Pages (For developers - 5 minutes)

1. Create GitHub account if you don't have one
2. Create new repository: `ieeeday2026`
3. Upload all files from `ieee day` folder
4. Go to: Settings → Pages
5. Select `main` branch → Save
6. URL will be: `https://yourusername.github.io/ieeeday2026/`

**Pros:**
- ✅ Free forever
- ✅ Version control
- ✅ Easy to update
- ✅ Professional URL

---

### Option 3: Vercel (Alternative to Netlify)

1. Go to: https://vercel.com
2. Sign up with GitHub
3. Import project → Upload `ieee day` folder
4. Deploy
5. Get URL like: `https://ieeeday2026.vercel.app`

## 🔧 If Something Goes Wrong

### Website Not Loading:
1. Check URL is correct
2. Check internet connection
3. Clear browser cache (Ctrl+Shift+Delete)
4. Try different browser

### Slow Loading:
1. Check WiFi capacity
2. Enable offline mode (service worker)
3. Use backup tablets with pre-loaded website

### QR Code Not Working:
1. Check QR code scans to correct URL
2. Make sure URL doesn't have typos
3. Use backup: Share URL via WhatsApp/Text

### Emergency Backup:
- Paper maps at all entrances
- Volunteers with tablets
- Printed event schedule
- Coordinator phone numbers visible
